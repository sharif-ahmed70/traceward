# CSP Week 1 Artifacts

This directory contains contract-compatible mock outputs for Member 5's Week 1 CSP and explainability work.

- `mock_csp_case.json` — variables, domains, constraints and a feasible Backtracking schedule.
- `mock_explainability.json` — human-readable examples for risk, attack-path and patch-priority explanations.

The schedule is intentionally described as **feasible**, not optimal. No optimization objective is implemented in Week 1.
