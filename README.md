# TraceWard

TraceWard is a university AI Lab project designed to analyze cybersecurity risks, predict vulnerability risk levels, identify possible attack paths through network infrastructure, and prepare practical remediation plans.

## Main Components

- **K-Means** — group similar vulnerability patterns
- **KNN** — predict vulnerability risk
- **A\* Search** — identify concerning attack paths
- **CSP** — prepare remediation schedules
- **Explainability** — explain important system decisions
